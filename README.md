# food_ordering_website

A modern and responsive **Food Ordering Website** built using **HTML, CSS, and JavaScript**. This project provides an attractive and user-friendly interface where users can browse food categories, explore restaurants, search dishes, and manage their shopping cart.

# 📌 About the Project

The **Food Ordering Website** is a frontend web application developed as part of my internship project. It focuses on creating an engaging and responsive user interface for an online food ordering platform.

The project allows users to browse different food categories, explore restaurant menus, search for food items, add products to their cart, and enjoy a smooth browsing experience.
